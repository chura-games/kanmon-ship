# 関門汽船 運転シミュレーター（唐戸 ⇄ 門司港）

関門海峡を渡る連絡船を操船して、唐戸桟橋から門司港桟橋へ着岸するブラウザゲームです。
three.js（WebGL）で動き、インストールは不要です。

> 本作は非公式のファンメイド作品です。実在の事業者・施設とは関係ありません。

## 遊び方

| 操作 | キー | スマホ |
| --- | --- | --- |
| 速力（前進・後進） | W / S | 左の速力レバー |
| 舵 | A / D | 右の舵スライダー |
| 左右へ平行移動 | Q / E | 「左へ平行」「右へ平行」ボタン |
| 機関停止 | X | — |
| 視点（追従・操舵席・右ミラー・客室・俯瞰） | C / 1〜5 | 設定メニュー |
| 汽笛 | H | 設定メニュー |

着岸：桟橋の防舷材に船速 1.2kn 未満・平行 ±10°・間隔 1m 以内でそっと横付けすると、係留索が取られ、渡し板が掛かって乗客が下船します。

## ファイル構成

```
index.html        画面の骨組み（HUD・メニュー・案内画面）
css/style.css     見た目（ライト／ダークテーマ対応）
models/ferry.glb  船の3Dモデル（外装・操舵席・客室）。Blender で編集できます
js/models.js      3Dモデルの読み込みと、ゲーム本体の起動
js/core.js        基盤：ユーティリティ、地形の関数、波、レンダラー、空、水面シェーダー
js/world.js       世界：地形、街並み、夜景の光、関門橋、桟橋、港の設備、大型船
js/ferry.js       船：船体モデルの組み込み、操舵席の計器・右ミラー、船首波
js/effects.js     演出：航跡、水しぶき
js/game.js        ゲーム：時刻・波の設定、操船物理、泡粒、海の生き物、排気、着岸・係留
js/ui.js          操作と表示：カメラ、HUD、ミニマップ、メニュー、効果音
js/main.js        メインループ：画質の自動調整、水面反射、毎フレームの更新
js/vendor/        three.js r128 の GLTFLoader（.glb の読み込み用）
```

JS は普通の `<script>` として読み込まれ、ファイル同士は共通の変数・関数を使い合っています。`js/models.js` が 3D モデルを読み終えてから、残りのファイルを **`GAME_SCRIPTS` に書かれた順番で** 読み込みます。順番は変えないでください。

外部から読み込むのは three.js r128（cdnjs）と Google Fonts だけです。

## 3Dモデルを Blender で編集する

船の形は `models/ferry.glb` に入っています。地形・街並み・橋・桟橋・ほかの船などは、まだ `js/world.js` のコードで作っています。

1. Blender で **ファイル → インポート → glTF 2.0** から `models/ferry.glb` を開きます。
2. 編集したら **ファイル → エクスポート → glTF 2.0** で、フォーマットを「glTF バイナリ (.glb)」にして同じ場所へ上書きします。
3. ブラウザを再読み込みすると反映されます。

向きと大きさ：Blender 上では X が船首、Z が上、-Y が右舷で、1 = 1m です。原点は船の中央・水面の高さです。

ゲームは次のオブジェクトを **名前で探して** 動かしたり表示を切り替えたりします。形やマテリアルは自由に変えられますが、名前を変えたり消したりすると起動時にエラーになります。回転・拡大縮小の「適用」もしないでください（動きの軸がずれます）。

| 名前 | ゲーム側の使い方 |
| --- | --- |
| `radar` | 回り続けます |
| `flag` / `ensign` | 頂点を揺らしてはためかせます（旗竿側の端がオブジェクトの原点） |
| `helm_wheel` / `helm_lever_1` / `helm_lever_2` / `helm_joystick` | 舵・速力・スラスターの操作に合わせて回します |
| `screen_radar` / `screen_chart` / `screen_gauge` | レーダー・海図・計器の画面を描き込みます |
| `gangway_hinge_stbd` / `gangway_hinge_port`（なくてもよい） | 船の渡し板。立てて格納した状態で作っておくと、着岸した側をヒンジ（オブジェクトの原点）で桟橋へ倒し、出航前に戻します。なければコードの渡し板を使います |
| `cleat_s`（なくてもよい） | 船首側の係留索を取る位置 |
| `mirror` / `mirror_glass`（なくてもよい） | 右舷ミラー。あれば `mirror_glass` に後方の映像を映し、ミラー視点はその位置から見ます |

名前の末尾に付く `__glb` は無視します（`radar__glb` は `radar` として扱います）。半透明のマテリアル（ガラス）は影を落とさず、水面のあとに描きます。

操舵席視点の目の位置、客室の照明、航海灯、排気の煙、船首波、係留索・渡し板の位置、当たり判定は、モデルではなくコード側の数値（`js/ui.js` の `updateCamera`、`js/ferry.js` の `HULLF` など）で決まります。操舵席を動かしたり船体の輪郭を大きく変えたりしたときは、そちらも合わせてください。

## GitHub Pages で公開する

1. このフォルダの中身をそのままリポジトリに置きます（`index.html` がリポジトリの一番上に来るように）。
2. リポジトリの **Settings → Pages** で、Source を「GitHub Actions」にします。
3. `main` に push すると `.github/workflows/pages.yml` が動いて公開されます（**Actions** タブから手動でも実行できます）。1〜2分後、`https://ユーザー名.github.io/リポジトリ名/` で遊べます。

パソコンで試すときは、このフォルダで `npx serve` や `python -m http.server` などの簡易サーバーを立てて開いてください。`index.html` をダブルクリックして開くと、ブラウザが `file://` からの 3D モデルの読み込みを止めるため動きません。
